# MLOps Starter Project

## Deskripsi
Project ini adalah fondasi awal untuk pengembangan machine learning yang terstruktur, reproducible, dan siap untuk kolaborasi tim.

## Struktur Project
- `frontend/`: Wajah aplikasi (UI/UX).
- `backend/`: Mesin aplikasi (API, business logic).
- `model/`: Otak ML (Training/inference code & artefak).
- `data/`: Bahan bakar (raw dan processed dipisahkan).
- `tests/`: Quality control (pengujian code).
- `docs/`: Manual dan dokumentasi teknis.

## Setup
1. Clone repository: `git clone <url>`
2. Buat virtual environment: `python -m venv venv`
3. Install requirements: `pip install -r requirements.txt`

## Tech Stack
Python, Git, GitHub, FastAPI, Scikit-learn.
